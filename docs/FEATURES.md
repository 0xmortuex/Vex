# Vex features

Generated by `node scripts/gen-features-doc.js` from the feature manifests and the catalogue. Do not edit by hand: change the manifest or the catalogue entry and run the script again. `tests/renderer/featureDocs.test.js` fails when this file is out of date or a manifest has no line.

Features listed: 567.

How to read it: `Ctrl+K` is the command bar; type the quoted phrase. "Settings > X" is the section whose heading starts with X. A feature marked New starts switched off on a profile that already existed (a brand-new profile uses the feature's own default).

## Tabs & windows

How Vex holds the pages you have open.

- **Evening tab cleanup** (`tab-cleanup`): Once an evening, lists tabs that have sat unused for days and second copies of another open tab, with one button to archive them into the Library and an Undo. The mode is Ask (default) or Off, in the Daily tools block of Settings > Workflow and chains.
  - Open: Ctrl+K: "Archive This Tab and Close It", "Tidy Stale Tabs Now"; Settings > Workflow and chains (the Daily tools block).
- **Sleeping tabs** (`tab-auto-sleep`): An idle tab gives its memory back and parks itself; it returns exactly where you left it, scroll position included.
  - Catalogue: (`tab-sleep`).
  - Open: Ctrl+K: "Sleep Tab".
- **Add new tabs to the group they match** (`tab-auto-group`): A new tab that matches an existing group is moved into it. The switch is in Settings > Smart Tab Grouping.
  - Open: Settings > Smart Tab Grouping.
- **Discord memory care** (`discord-memory-care`): Three opt-in helpers for a Discord panel that grows. The over-limit notice stays on screen until you answer it (Refresh Discord now, Not now for an hour, Turn on automatic refresh) and leaves a row in the Inbox. Automatic refresh reloads the hidden panel at most once every six hours, never in a call, a screen share or while the microphone or camera is in use, and not within half an hour of an unread count. Rest mode tells a hidden Discord the truth about being hidden so it can idle; notifications can lag while it rests. On an existing profile all of it starts off; turn it on in Settings > Performance.
  - Open: Ctrl+K: "Measure Discord over 10 minutes", "Plugin memory: which Vencord plugin costs how many MB"; Settings > Panels and messages.
  - Default: New: starts off on an existing profile until you switch it on.
- **Ctrl+Tab by recency** (`tab-mru`): Ctrl+Tab switches in the order you used the tabs last, like Alt+Tab. On an existing profile it starts off; turn it on in Settings > Tab tools.
  - Open: Settings > Tab tools.
  - Default: New: starts off on an existing profile until you switch it on.
- **Search open tabs** (`tab-search`): A list of every open tab, last used first, narrowed as you type (Ctrl+Alt+Z). On an existing profile it starts off; turn it on in Settings > Tab tools.
  - Open: Ctrl+K: "Search open tabs"; Settings > Tab tools.
  - Default: New: starts off on an existing profile until you switch it on.
- **Back and Forward list** (`nav-history-menu`): Right-click or hold Back and Forward to see the list of pages behind and ahead. On an existing profile it starts off; turn it on in Settings > Tab tools.
  - Open: Settings > Tab tools.
  - Default: New: starts off on an existing profile until you switch it on.

  - Open: Settings > Tab tools.
  - Default: New: starts off on an existing profile until you switch it on.

  - Default: New: starts off on an existing profile until you switch it on.

- **Measure Discord over 10 minutes** (`discord-measure`): Samples the Discord panel’s memory and JavaScript heap every 30 seconds while it is hidden, and shows the trend. - **Plugin memory: which Vencord plugin costs how many MB** (`discord-plugin-ram`): Asks Chromium which Vencord plugin allocated how much memory in the Discord panel over a short window you choose (read-only, about a minute; Electron cannot hand that profile back when Discord’s call stacks are very deep, and Vex then says so), and can turn plugins off to measure their real cost: one at a time (about 5 minutes per plugin) or in groups of 8 (about an hour for 60 plugins). Opt-in, and every plugin is put back. Results go into the Why is Discord big? report with their limits stated. Numbers and plugin names only; nothing is sent.

## AI

An assistant and an agent, on your own backend — cloud, local, or on-device.

- **Ask across my tabs** (`workflow-ask-tabs`): Ask a question and get an answer from the text of your open tabs, with the tab each passage came from. Your question and the passages go to your AI backend, so use the local one if you want it to stay on this PC. Settings > Workflow and chains.
  - Open: Ctrl+K: "Ask across my tabs"; Settings > Workflow and chains.
- **Knowledge base** (`knowledge-base`): Searches what you kept (bookmarks, notes, highlights, archived pages) by meaning, and lets a local model answer from it with the sources named. Off by default: turn it on in Settings > Knowledge base.
  - Open: Ctrl+K: "Search My Knowledge Base", "Ask My Library (Local AI)", "Ask About This Page (Local AI)", "Ask About My Open Tabs (Local AI)", "Related To What I'm Reading"; Settings > Knowledge base.
- **Sensitivity gate before cloud AI** (`ai-sensitivity`): Checks a request for the cloud AI before it is sent, holds it back if it looks sensitive, and sends it only if you say yes; each decision is in Why did that happen.
  - Open: Settings > AI.
  - Default: always on, no switch.
- **Scheduled AI recipes** (`ai-recipes`): A recipe pairs a saved AI skill with an optional page to read and a reminder. When the reminder fires Vex opens the recipe ready to go. Reach it from Ctrl+K with "AI recipes". On an existing profile it starts off; turn it on in Settings > Scheduled AI recipes.
  - Open: Ctrl+K: "AI recipes".
  - Default: New: starts off on an existing profile until you switch it on.
- **Watch with judgement** (`watch-judgement`): Adds a condition in your own words to a page watch, such as "only if the price drops". Your local model decides if a change matters. Reach it from Ctrl+K with "Watch conditions". On an existing profile it starts off; turn it on in Settings > Watch with judgement.
  - Open: Ctrl+K: "Watch conditions".
  - Default: New: starts off on an existing profile until you switch it on.
- **Long-document engine** (`longdoc-engine`): Lets other AI features work on documents longer than one request, by summarising in pieces and joining the pieces. Settings > Long documents. On an existing profile it starts off; turn it on in Settings > Long documents.
  - Open: Settings > Long documents.
  - Default: New: starts off on an existing profile until you switch it on.
- **Thread digest** (`thread-digest`): Digests a long thread, from your selection or the page: decisions, open questions and what is new since you last read, with your local model. On an existing profile it starts off; turn it on in Settings > Thread digest.
  - Open: Ctrl+K: "Digest this thread (since I last read)"; Settings > Thread digest.
  - Default: New: starts off on an existing profile until you switch it on.
- **Draft into the field** (`draft-in-field`): Rewrites or drafts the text of the box you are typing in, shows the difference, and changes the box only when you press the button. On an existing profile it starts off; turn it on in Settings > Draft into the field.
  - Open: Ctrl+K: "Draft into the field I'm typing in"; Settings > Draft into the field.
  - Default: New: starts off on an existing profile until you switch it on.
- **Embedding model manager** (`embedding-manager`): Shows which embedding models your own Ollama has and picks the one Recall uses to search by meaning; it can ask Ollama to download one after you confirm. On an existing profile it starts off; turn it on in Settings > Search by meaning (embedding model).
  - Open: Settings > Search by meaning (embedding model).
  - Default: New: starts off on an existing profile until you switch it on.
- **Show-me-where citations** (`answer-citations`): Under an AI answer, "show me where" marks the passage on the page each claim came from. On an existing profile it starts off; turn it on in Settings > Knowledge: show-me-where citations.
  - Open: Settings > Knowledge base.
  - Default: New: starts off on an existing profile until you switch it on.
- **Site instructions and typed skills** (`site-instructions`): A standing instruction added to every AI chat on one site, and skills you bound to that site. On an existing profile it starts off; turn it on in Settings > Site instructions.
  - Open: Ctrl+K: "AI: Instruction for this site", "AI: Skills for this site"; Settings > Site instructions.
  - Default: New: starts off on an existing profile until you switch it on.
- **Pinned agent tasks** (`agent-pins`): Pins a saved agent task as its own Ctrl+K command, "Run task: name". Use "Pin a Saved Task to Ctrl+K" and "Unpin a Task From Ctrl+K" to manage them. On an existing profile it starts off; turn it on in Settings > Pinned agent tasks.
  - Open: Ctrl+K: "Pin a Saved Task to Ctrl+K", "Unpin a Task From Ctrl+K"; Settings > Pinned agent tasks.

  - Open: Ctrl+K: "Recall — Search What You've Read"; sidebar panel: recall.

  - Open: sidebar panel: recall.
- **remember** (`remember`): Finds a page by what it was about rather than what it was called — "that article about DPI".
